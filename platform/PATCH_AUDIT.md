# Carried patch audit

The ABSD standard-library delta is a small carried platform patch, not a Rust
fork. It applies to exactly one content-pinned library snapshot and changes 30
files: 1,968 insertions and 47 deletions. All but 50 inserted lines are in
ABSD-named files (the PAL and `std::os::absd`); the rest route to them, select
generic upstream backends, or make the pinned offline build resolvable.

## Platform semantics

| Patched path | Classification | Reason |
| --- | --- | --- |
| `std/src/sys/pal/mod.rs` | routing | Select the ABSD PAL instead of the generic unsupported PAL. |
| `std/src/sys/pal/absd/mod.rs` | PAL | Initialize arguments, route abort to process exit 101. |
| `std/src/sys/pal/absd/os.rs` | PAL | Upstream's unsupported OS operations, except three: `getcwd`/`chdir` read and set the runtime's working directory (process memory, from the startup record, else `/`; `chdir` requires an existing directory), and `getpid` is the kernel's PID. |
| `std/src/sys/stdio/mod.rs` | routing | Select handle-backed ABSD standard I/O. |
| `std/src/sys/stdio/absd.rs` | PAL | Implement bounded stdin/stdout/stderr reads and writes and translate defined ABSD failures into `ErrorKind`; no file descriptors are introduced. Stderr goes to the startup record's stderr handle when it names one, else the console. |
| `std/src/sys/process/mod.rs` | routing | Select the ABSD process backend. |
| `std/src/sys/process/absd.rs` | PAL | `std::process` two ways, forwarded to the runtime's `__absd_std_process_*`/`__absd_std_handle_*` hooks (kernel `docs/PROCESS-STARTUP.md`). **From a file** (no broker handles): the runtime reads the program (absolute, or relative with a `/`; a bare name is `InvalidInput`, no PATH) from the mounted filesystem and starts it with the kernel's `spawn_image`, passing argv, the whole environment (ours plus the `Command`'s changes), the working directory, and a read-only filesystem view; piped, null (a closed writer or a drained, discarded reader), and inherited (our own handle) stdio, `io::stdout()`/`io::stderr()`, and a pipe end this process holds (`Stdio::from(ChildStdout)` and the like: the child gets a copy with only the stream's right, read for stdin and write for output, the kernel refusing a right the end lacks; a successful spawn consumes the end, closing our copy at once, and a `Command` whose end was consumed refuses to spawn again with `InvalidInput`; a refused spawn consumes nothing); `wait`/`try_wait`/`kill` are the kernel's. **Through init's broker** (kernel `docs/BROKER.md`), unchanged: `spawn` spends one slot per request (program path exactly as given), refusals map to `ErrorKind`s (not permitted is `PermissionDenied`) and spend nothing; piped stdio is the slot's pipes; null stdin closes the writer; null or inherited stdout/stderr is drained (discarded or copied to this process's stream) while the parent waits; `output`/`wait_with_output` alternate one-tick-bounded reads of both streams; `wait`/`try_wait` read EXITED (the i64 outcome; `code()` only for non-negative statuses); environment variables, a working directory, inherited stdin, and `kill` are `Unsupported` there. Files as stdio, and pipe ends on the broker path, are `Unsupported`. |
| `std/src/sys/env/mod.rs` | routing | Select the ABSD environment and upstream's owned `Env` iterator. |
| `std/src/sys/env/absd.rs` | PAL | Read-only environment from the startup record's policy-given section (`__absd_std_environ`); empty otherwise. `set_var`/`remove_var` are `Unsupported`. |
| `std/src/sys/args/mod.rs` | routing | Reuse the generic owned `Args` iterator and select ABSD argument capture. |
| `std/src/sys/args/absd.rs` | PAL | Copy the runtime's bounded, NUL-terminated startup argument vector into ordinary `OsString` values. |
| `std/src/sys/alloc/mod.rs` | routing | Select `System` allocator hooks for ABSD. |
| `std/src/sys/alloc/absd.rs` | PAL | Forward `System` allocation to the process-local mapped allocator. |
| `std/src/sys/exit.rs` | PAL | Forward `std::process::exit` to ABSD process exit. |
| `std/src/sys/io/error/mod.rs` | generic backend | Use upstream generic error representation; ABSD does not claim Unix error numbers. |
| `std/src/sys/thread_local/mod.rs` (two hunks) | target policy | Select upstream single-thread TLS and its no-thread cleanup guard. |
| `std/src/sys/fs/mod.rs` | routing | Select the ABSD file backend and export its no-clobber rename to `std::os::absd`. |
| `std/src/os/absd/process.rs` (and one `ChildPipe::handle` accessor in `sys/process/absd.rs`) | PAL extension | `AsRawHandle` for `ChildStdin`/`ChildStdout`/`ChildStderr` (under `absd_fs_ext`): the kernel handle of a child's pipe end, still owned and closed by the std object. A single-threaded server multiplexing several children (sshd) waits on each pipe with a bound through the runtime's `read_within`/`write_within` (the kernel's timed `transfer`), which std's blocking pipe reads cannot express. No new semantics. |
| `std/src/os/mod.rs`, `std/src/os/absd/{mod,fs}.rs` | PAL extension | Unstable `absd_fs_ext`: `MetadataExt` (filesystem id, object serial, link count), `PermissionsExt::from_readonly`, and `rename_noreplace`. These name what an ABSD object has instead of imitating Unix metadata. |
| `std/src/sys/path/unix.rs` | target policy | A `/`-rooted path is absolute on ABSD, as on Unix; ABSD has no path prefixes. |
| `std/src/sys/fs/absd.rs` | PAL | The file cursor is an `AtomicU64` (not a `Cell`), so `File` is `Sync` as on every other target; NQ's CLI needs that to carry a `tempfile::PersistError` in `anyhow`. Forward `std::fs` to the runtime's storage hooks: open (read, write, append, create, create-new, truncate), positional read/write, length, `set_len`, sync, stat/fstat, read-only permission, mkdir, rmdir, unlink, rename, no-clobber rename, read_dir (a snapshot), canonicalize, and flock-shaped `lock`/`try_lock`/`unlock` without waiting. Exactly two object kinds convert (1 file, 2 directory); any other kind word is the runtime's -5 error from stat and fstat, never a file, and a read_dir entry of unknown kind (marked 0 by the runtime) stays listed with a `file_type()` that is that error and a `metadata()` that is `stat` of its path (SPEC A21). The internal V2 stat/fstat/readdir hooks carry mtime in a 48-byte record; V1 remains 40 bytes for the live C kit. `Metadata::modified` preserves whole UTC Unix seconds, returns Unsupported for unknown (0), and never reads the clock. Access/creation times, timestamp setters, owners, modes, hard links, and symlinks stay unsupported. New std with old runtime fails to link on the V2 symbols; old V1 std/C clients remain compatible with the new runtime. The runtime serves the ABSD filesystem when mounted, else the one-name `ledger` region. |
| `std/src/sys/time/mod.rs` | routing | Select the ABSD monotonic clock. |
| `std/src/sys/time/absd.rs` | PAL | `Instant` from the kernel's PIT tick counter (about 1 kHz since boot). `SystemTime::now` is the kernel's CMOS RTC reading (`SYS_WALL_CLOCK`, through the runtime's `__absd_std_wall_clock_seconds`): whole seconds since the Unix epoch, the RTC declared to hold UTC, sub-second part zero, never corrected. A refused reading panics; no time is substituted. |
| `std/src/sys/random/mod.rs` (two hunks) | target policy | Select upstream unsupported entropy; general random-byte requests panic instead of returning fake entropy. The address-salted `HashMap` fallback remains upstream behavior, not an entropy service. |

The platform deliberately inherits upstream unsupported implementations for
network, environment mutation, and every other unimplemented OS surface. The
target has no Unix family, so it exposes no signal or POSIX API.
`std::thread::spawn` and TCP connect are executable matrix checks and return
`ErrorKind::Unsupported`; the same probe requires `Command` to refuse a bare
name (`InvalidInput`) and a path on a boot without a filesystem
(`NotFound`), and `current_dir` to be `/`.

## Offline-only scaffolding

| Patched path | Reason and removal condition |
| --- | --- |
| `std/Cargo.toml` | Cargo resolves dependency declarations for other targets even though ABSD cannot compile them. Several required crates are absent locally; retaining the individually available, irrelevant groups would only expand the pinned lock/cache contract. Remove this whole hunk when the Rust source and all registry inputs are fully vendored. |
| `unwind/Cargo.toml` | The irrelevant Xous-only `unwinding` crate is absent offline but is still resolved through `std`'s unwind dependency. Remove with a fully vendored source graph. |
| `sysroot/Cargo.toml` test dependency | The local cache lacks `getopts`, required by the source-tree `test` crate. `test` is not part of the ABSD build. The optional profiler dependency and feature were retained after an executable build proved they do not need pruning. |
| `proc_macro/Cargo.toml` | The snapshot asks for unavailable `rustc-literal-escaper` 0.0.7. It is redirected to the checked-in 0.0.5 source already used by the pinned compiler ecosystem. It is build-only and is not linked into ABSD programs. |
| `sysroot/Cargo.toml` default features | Select panic-abort only. This is target policy, not an emulated unwind implementation. |

The pinned library lockfile makes the offline resolution exact. During the
audit, removing `coretests`/`alloctests`, removing the optional profiler, and
adding `panic_abort` to the dummy sysroot were all proven unnecessary and
deleted from the patch. Restoring `test` failed specifically on absent
`getopts`; restoring the Xous dependency failed specifically on absent
`unwinding`.

Only one installed `rust-src` snapshot exists on this host, so there was no
nearby source snapshot against which a meaningful conflict count could be
measured. Supporting another version was intentionally not attempted.

## Licensing and attribution

A carried patch contains upstream's lines as context and removals, and
ABSD's lines as additions. Upstream's terms continue to apply to upstream's
lines. The licence of ABSD's lines is not decided, so the patch files carry
no licence identifier; they are also content-pinned by
`scripts/verify-inputs.sh`. `provenance.toml` is the checked record.
