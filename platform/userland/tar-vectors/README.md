# Independent ustar vector

basic.ustar was generated with Python3.12.3 tarfile, USTAR_FORMAT, TarInfo("file"), mode0644, size3, mtime0 and data b"abc". Other fields use TarInfo defaults; recordblocking is10240bytes. This is an independent standard writer, not output from the port. Exact digest in SHA256SUMS. userland/test_tar.py verifies regeneration equality, checks parse/extract, and builds checksum/field/truncation variants from this retained vector. Additional fullwidth pathname vectors are deterministically generated by the same independently implemented writer.
